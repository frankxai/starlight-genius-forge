## Core Features

### 1. Talent Discovery
- Agent swarms scan public signals (GitHub, X, portfolios, publications) with ethical, privacy-first rules (public data only).
- Self-submission portal with AI profile analysis (skills, past impact, location signals for JP/PH/ID priority).
- Dream100-style scoring + fit analysis adapted for "genius despite constraints."

### 2. Competitions & Challenges
- Themed, high-signal competitions (e.g., "Sovereign AI Agents for Southeast Asia Impact", "Japan Creative Tech Forge", "PH/ID Worldbuilder Lore & Systems").
- Multi-stage: Submission → AI + Community judging (Starlight evals) → Live demos → Funding/matching round.
- Prizes: Exposure on frankx.ai / arcanea.ai / gencreator.ai, mentorship, micro-grants, direct HNW intros, marketplace placement.

### 3. Builder Support
- Seamless integration with **GenCreator-OS Studio**, **Arcanea tools**, **arcanea-code** CLI, delegation to Claude Code / Codex / Grok workflows.
- MCP servers, skills packs, and swarm configurations available via The Exchange.
- Agents help scope, architect, code, test, and launch projects.

### 4. HNW Community & Matching
- Private/high-signal "Lumina Investors Guild" (built on investor-agent-skills).
- Talent projects surfaced as curated deal flow.
- Syndication, co-building, mentorship, and success-based economics.
- Events, content, and value-first onboarding for backers.

### 5. Community Layer
- Agent-moderated guilds/channels (Telegram, Discord, or custom).
- Talent + HNW matching engine.
- Ongoing cohorts, masterminds, and skill-sharing.
