## 1. Purpose

Turn raw ideas into documented, quantified, validated, executable, and monetizable assets using sovereign agent swarms — without fragmenting the FrankX / GenCreator / Arcanea / Starlight stack.

**Standing media rule:** Content images/video use **native Grok / xAI CLI tools only** (enabled `xai` image plugin). Never default to FAL unless Frank explicitly overrides.

## 2. Idea Lifecycle (7 stages)

| Stage | Goal | Primary tools | Exit criteria |
|-------|------|---------------|---------------|
| **1. Capture** | Ingest signals + human sparks | SIS memory, Hermes, X/web scans, self-submit | Idea card with provenance |
| **2. Refine** | Clarify problem, ICP, constraints | Multi-LLM council, model-routing | One-page brief |
| **3. Quantify** | Score impact, market, feasibility, virality, ethics | Metrics templates, Arena-style rubrics | Scorecard ≥ ship threshold |
| **4. Validate** | Competitions, pilots, A/B, community | Genius Forge comps, live demos | Evidence pack |
| **5. Execute** | Build with GenCreator / coding CLIs / Arcanea | Grok, Claude Code, Codex, AGY, OpenCode | Working artifact + proof |
| **6. Document** | Living MD + dashboards + provenance | Repo docs, Obsidian, queen reports | Searchable SSOT |
| **7. Monetize** | Polar tiers, marketplace, content flywheel, success fees | Polar, Exchange, sponsored comps | Revenue path or explicit free tier |

## 3. Architecture (layers)

```
Capture / Memory (SIS)
        ↓
Refine + Quantify (multi-LLM council + Arena)
        ↓
Validate (Competitions / pilots / HNW review)
        ↓
Execute (GenCreator Studio · Arcanea · multi-CLI)
        ↓
Document + Monetize (repo SSOT · Polar · marketplace)
```

**Talent track** = original Genius Forge (JP/PH/ID focus + HNW Lumina guild).  
**Domain modules** = plug-ins (football first; fitness, creative, finance next).

## 4. Multi-CLI competition (default for non-trivial ideas)

Route per coding-agents MCR:

| Work | CLI |
|------|-----|
| Cinematic / creative / native image prompts | **Grok CLI** |
| Architecture judgment / PR review | **Claude Code** |
| Implementation loops | **Codex** |
| Bulk / Gemini grunt | **AGY** |
| Flexible free models | **OpenCode** |
| Orchestration / CoE / receipts | **Hermes Queen** |

Every major idea run should produce **≥2 competing drafts** + a short judge table (correctness, depth, taste, actionability, cost).

## 6. Quantification template (every idea)

1. **Attention** — reachable audience, channel fit  
2. **Economic** — TAM/SAM/SOM or revenue path  
3. **Social / connection** — community / belonging metrics  
4. **Evolutionary / excellence** — skill, resilience, selection pressure (for sports/culture ideas)  
5. **Feasibility** — days to pilot, CLI/agent cost, disk/CI budget  
6. **Ethics** — 6-Pillar Ethics + bias / exploitation checks  
7. **Ship bar** — 0–10 overall; ship ≥7, iterate 5–6, kill <5  

## 7. Operator loop (Hermes)

1. Load `todo-discipline` + `coding-agents` + `starlight-queen`  
2. Capture idea → idea card  
3. Dispatch multi-CLI compete (max 3 leaves)  
4. Judge + merge best  
5. Write artifacts into this repo  
6. Draft PR (not force-merge)  
7. Queen receipt under `starlight/queen/reports/`  
8. Todo merge+read before handover
