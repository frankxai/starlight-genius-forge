## 2. Viral posting playbook (TikTok / Instagram / X)

| Phase | When | Action |
|-------|------|--------|
| Pre | 24h before knockout | Teaser: one still + “who wins?” poll |
| Peak | 0–30 min after goal / FT | Hero still + emotion caption |
| Mid | Next morning | Carousel: 3 teams + “series continues” |
| Evergreen | Off-match days | Character lore, “fan of the day”, tactics-anime blend |

**Cadence (final week):** 1–2 posts/day max quality; series = one primary team arc.  
**Captions:** emotion first → team → soft CTA (follow for series). Light Idea Forge / brand only after value.  
**Hashtags:** `#WorldCup2026` `#AnimeFootball` `#FootballFans` + team tags.  
**Accounts:** dedicated theme account OR push existing; consistency > spam.  
**Log:** path, URL, views@24h, saves, follows — back to queen report.
