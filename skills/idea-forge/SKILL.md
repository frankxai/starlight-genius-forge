# Starlight Idea Forge (skill draft)

## Overview

Operate the **Idea lifecycle** on top of Genius Forge (talent + competitions + build + HNW). Full doctrine: `docs/IDEA-FORGE.md`. Domain packs: `docs/FOOTBALL-DOMAIN.md` and future modules.

**Stages:** Capture → Refine → Quantify → Validate → Execute → Document → Monetize.

## When to Use

- User dumps raw ideas / “evolve this” / multi-hour idea work
- Football / World Cup / meaning / agent business / viral content ideas
- Multi-CLI compete on briefs or implementations
- Genius Forge comps/talent framed as idea campaigns
- Packaging content visuals for Idea Forge

**Don’t use for:** inventing Arcanea canon; private brand growth as product features (route private instance); FAL-primary image pipelines for this product line.

## Prerequisites

1. Load `agent-workspace-bootstrap` — work in verified child repo `starlight-genius-forge` (or execute target product repo).
2. Read `docs/IDEA-FORGE.md` (architecture + gates).
3. If football: `docs/FOOTBALL-DOMAIN.md` + re-verify live sports facts before publish.
4. 6-Pillar gate on stage transitions.

## Procedure

1. **Classify** domain + idea class; create/update IdeaCard skeleton (see IDEA-FORGE data model).
2. **Capture** raw + one_liner + tags + provenance. Done when card exists.
3. **Refine** with multi-CLI compete (≥2 independent passes) → score → synthesize → lock brief.
4. **Quantify** 10-dimension scorecard + effort/risk/confidence; rank vs portfolio.
5. **Validate** cheap experiment or public signals + Ethics; explicit go/no-go.
6. **Execute** in correct repo (4-fact git); real tool proof; GenCreator/coding-agents/Arcanea as needed.
7. **Document** SSOT paths + memory; patch this skill if process improved.
8. **Monetize** path or deferred date (open-core, Exchange, HNW, content, sponsorship).

### Multi-CLI compete (mandatory for high-value Refine)

- Same scorecard for all competitors.
- Isolated contexts; collect variants; council/human judge; synthesize winner.
- CLIs: Claude Code, Codex, Grok Build, Hermes, OpenCode as available.

### Media (HARD)

- **Native Grok / xAI image only** for Idea Forge stills (Grok Imagine / XAIImageGenProvider).
- Do **not** use Hermes FAL `image_generate` as primary. Missing FAL key → route xAI or stay text-only.
- Disk-tight hosts: default text-only; no media bloat in git.

## Common Pitfalls

1. Single-pass “refine” without multi-CLI evidence.
2. Execute as plan-only (no real run/proof).
3. FAL/default image_generate for Idea Forge content.
4. Publishing sports facts without live check.
5. Writing in estate root / universe / wrong repo.
6. Personal brand live ops on public product tree.
7. Skipping Ethics on sports monetization language.
